# Deltamod Community 2.1.0

Minor release with improved macOS mod workflows, native patch and import
reliability, dependency maintenance, and a refreshed download guide.

## Highlights

- Improve macOS mod acquisition and patching through managed game copies,
  validated Windows reference files, and careful preservation of original apps.
- Strengthen archive validation, native patch staging, path containment,
  rollback, and recovery boundaries.
- Improve GameBanana catalogue and comment workflows, and interface localization.
- Update React and React DOM to 19.3.1, Tauri CLI to 2.12.4, Vite to 8.3.5,
  Vitest to 5.0.5, Playwright to 1.64.1, and Zod to 4.6.7.
- Update Cargo dependencies and pinned GitHub Actions, repair the Windows
  Clippy CI regression, and address high-severity npm security advisories
  involving Vite, Zod, undici, and follow-redirects.
- Correct README download guidance, version links, and installer naming for
  the canonical community repository.

## Compatibility and publication requirements

- Windows x64, Linux x64, Intel macOS, and Apple Silicon macOS remain the
  supported packaging targets. See the README for support levels.
- On macOS, xdelta patches targeting data.win need reference files from
  a matching Windows game version. Native desktop .csx execution is unavailable
  on every platform, including platforms that bundle the standalone CLI.
- A stable release must pass the cross-platform package/smoke and updater
  signing gates. Windows publisher signing and macOS notarization are not
  provided. Linux .deb updates are manual.
- When published, assets include SHA256SUMS.txt and GitHub attestations;
  do not interpret unpublished builds or validation jobs as releases.

# Deltamod Community 2.0.18

Planned stable release.

This release completes the Community roadmap foundations around transactional
mod management, recoverable profiles, the Tauri/Rust runtime, and a more useful
player-facing interface.

## Highlights

- Add transactional install, update, uninstall, verify, repair, profile switch,
  and restore-last-working-state operations with durable journals and idempotent
  operation identities.
- Publish patch output exclusively through the Rust lifecycle filesystem boundary,
  with staging, rollback, cancellation, timeout, process-tree cleanup, and
  traversal/link/reparse-point protection.
- Turn Installed Mods into a control center with health, source, version, hash,
  files, conflicts, operations, recovery, diagnostics, and profile actions.
- Normalize GameBanana, Nexus Mods, ModDB, and local archives behind bounded
  provider contracts, caching, offline fallback, and structured errors.
- Bundle four additional DELTARUNE themes and eight UNDERTALE location themes,
  including New Home, with fixed manifests and recorded provenance.
- Improve the Chara encounter, startup flow, contrast, keyboard/focus handling,
  reduced-motion behavior, game selection, and game-aware mod filtering.
- Complete the Tauri command/event bridge, native protocol forwarding, installed
  package smoke contracts, five Rust worker protocols, and cross-platform release
  gates while retaining the fast shared renderer/domain tests.

## Reliability and release evidence

- Keep active and unfinished recovery state protected while enforcing bounded
  archive/cache, recovery-generation, and operation-history retention.
- Add a packaged capability probe that verifies persistence, theme loading, an
  actually resolvable game installation, and bounded unknown-command errors.
- Record the post-rewrite Windows benchmark at 1,664.31 ms median readiness and
  422.67 MiB median peak working set versus Electron's 1,513.96 ms and 728.60 MiB.
- Require target-native Rust tests for Windows, Linux, Intel macOS, and Apple
  Silicon macOS packages before installed-package smoke tests run.

## Remaining publication prerequisite

- Stable Windows/macOS publication remains fail-closed until the repository has
  publisher certificates and Apple notarization credentials. Linux remains a
  signed-checksum manual-download package without automatic updater artifacts.

# Deltamod Community 2.0.3

Released 2026-08-12.

This is the first stable release using the Tauri desktop shell. Download it
manually from the GitHub release page. In-app automatic updates are not enabled;
they will remain unavailable until a signed updater is configured.

Windows and macOS packages are not code-signed because this community project
does not currently have paid platform signing credentials. Operating systems
may show an unknown-publisher warning. Verify downloads against the attached
`SHA256SUMS.txt`; checksums verify file integrity, not publisher identity.

## Highlights

- Added a theme-aware animated startup sequence.
- Redesigned the Mod Shop with clearer source cards, image previews, loading
  states, search controls, and download/import progress.
- Improved GameBanana featured sorting and guarded pagination against duplicate
  requests.
- Improved Nexus Mods request coalescing, quota tracking, rate-limit handling,
  and authorization messaging.

## Fixed

- Resolved production dependency audit failures and updated vulnerable
  transitive dependencies.
- Stabilized the Electron smoke test by waiting for renderer navigation to
  finish before continuing.
- Prevented repeated external-catalogue requests while another request is still
  active.

## Nexus Mods status

Nexus Mods account connection is not enabled in this build because the
Deltamod Community application registration is still pending. The app shows a
pending-registration state instead of requesting or storing pasted API keys.
GameBanana, ModDB, and local mod imports remain available.

## Known limitations

- Windows and macOS artifacts are unsigned and may trigger platform warnings.
- Linux and macOS support remains experimental.
- Automatic updates are not available; install future releases manually from
  the official GitHub release page.
- Nexus Mods browsing and downloads will remain unavailable until application
  registration is approved and a future build supplies the SSO application ID.
